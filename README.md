# KarierMuda 🚀

KarierMuda adalah website landing page modern yang membantu mahasiswa dan fresh graduate menemukan peluang karier pertama mereka. Website ini menyediakan informasi lowongan, pencarian pekerjaan, bookmark, checklist persiapan karier, dan tampilan responsif yang dapat digunakan di desktop maupun mobile.

## ✨ Fitur

- Lowongan pekerjaan & magang
- Search lowongan
- Filter kategori pekerjaan
- Bookmark pekerjaan
- Dark mode
- Checklist persiapan karier
- FAQ interaktif
- Statistik pengguna
- Responsive design
- Animasi AOS

---

## 🛠️ Teknologi

- HTML5
- CSS3
- JavaScript
- AOS (Animate On Scroll)
- Google Fonts

## 🚀 Menjalankan Project

1. Clone repository

```bash
git clone https://github.com/username/kariermuda.git
```

2. Masuk ke folder project

```bash
cd kariermuda
```

3. Jalankan file:

```bash
index.html
```

Atau menggunakan Live Server di VSCode:

- Klik kanan `index.html`
- Pilih **Open with Live Server**
